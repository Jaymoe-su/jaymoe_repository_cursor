# Presentation Viewer Prototype

A click-through mockup of a presentation viewer interface that highlights key features of a new view setting for presentations.

## Features

This prototype demonstrates:

1. **Slide Navigation** - Click any slide thumbnail in the sidebar to navigate between slides instantly
2. **Task Organization** - Interactive 2x2 grid layout showing tasks organized by unit (PACAF, PACFLT, USARPAC, MARFORPAC)
3. **Formatting Toolbar** - Access formatting options, comments, and presentation controls
4. **Real-time Sync** - Collaboration status indicator showing active users

## How to Use

1. **Navigate Slides**: Click on any slide thumbnail in the left sidebar to jump to that slide
2. **Explore Features**: 
   - Click on task boxes to see feature highlights
   - Click on the sync button to see collaboration features
   - Click "Add comment" to see toolbar features
3. **Interactive Elements**: 
   - Hover over buttons to see tooltips
   - Click interactive elements to trigger feature highlights

## Setup

This prototype uses Next.js and React. No additional dependencies are required beyond what's already in the project.

## Key Interactions

- **Slide thumbnails**: Click to navigate and see slide navigation feature highlight
- **Task boxes**: Click to see task organization feature highlight
- **Sync button**: Click to see real-time collaboration feature
- **Menu items**: Click to explore different toolbar options
